## 1. Executive Summary

`remotedebugger` is a long-running root daemon on RDK CPE/STB devices whose sole purpose is to receive an "IssueType" string over rbus/IARM/WebConfig, resolve it against a JSON command profile, and execute the matched command list as **uid 0** via `systemd-run … /bin/sh -c <cmd>` (`src/rrdRunCmdThread.c:386`). The systemd unit (`scripts/remote-debugger.service:26-29`) applies **no privilege drop, no sandboxing, no `PrivateTmp`/`PrivateIPC`, and no capability bounding**. By design the daemon is therefore a remotely-triggerable root shell guarded only by (a) a JSON allow-list and (b) a five-entry `strstr()` deny-list. Both guards are trivially bypassable: the dynamic profile is loaded with a bare `fopen()` from an **attacker-writable mount** (`/media/apps/` or `/tmp/`, `src/rrdEventProcess.c:569-571`) with no signature/ownership check, and the deny-list is read **from the attacker's own JSON** (`src/rrdJsonParser.c:456-471`) — supplying `"Sanity":{"Check":{"Commands":[]}}` defeats it entirely.

The overall security posture is **critical**. Any local low-privilege process able to write under `/media/apps` (or `/tmp`) and reach the rbus socket — both default conditions under the stated threat model — obtains a **deterministic, single-shot root shell** with no memory corruption, no race, and no ASLR dependency. A second, independent route exists via the daemon's internal SysV message queue: it is created world-read/write (`msgget(1234, IPC_CREAT|0666)`, `src/rrdMain.c:157`) and carries **raw heap pointers** that the consumer dereferences without validation (`src/rrdMain.c:46-51`), yielding arbitrary-pointer-deref, arbitrary-free, double-free, and ASLR-defeat primitives in a uid-0 process from any local UID. Working proofs-of-concept for both chains exist in `/home/bow/Desktop/workflows_comparison/remote_debugger-1.3.3-ON/poc/`. **Seventeen distinct Critical findings** converge on the same architectural failure: untrusted input from writable filesystems and unauthenticated IPC is delivered to `/bin/sh -c` as root with the only filter under attacker control.

## 6. Recommendations

| Systemic issue | Concrete fix |
|---|---|
| **S1 — Untrusted profile source** | Never load command profiles from writable mounts. Hard-code `dynJSONPath` root to a read-only location, or require RDM-signed packages: before `readJsonFile()` (`src/rrdJsonParser.c:82`), `realpath()` the path, verify the prefix is `/etc/rrd/` or a verified RDM signature root, `lstat()` and reject if `st_uid != 0` or any path component is a symlink. Reject `pkg_inst_path` from IARM that does not canonicalise under `/media/apps/RDK-RRD-*/` (`src/rrdIarmEvents.c:342`). |
| **S2 — Attacker-supplied deny-list / blacklist filtering** | Delete the deny-list model entirely. Replace `isCommandsValid()` with a **positive allow-list** of commands defined **only** in read-only `/etc/rrd/remote_debugger.json`; in `invokeSanityandCommandExec()` (`src/rrdJsonParser.c:456-471`) and `getIssueCommandInfo()` (`:348-354`) read `Sanity` exclusively from `RRD_JSON_FILE`, never from `jsoncfg`. Make `isCommandsValid()` **fail-closed** on NULL/empty list (`src/rrdCommandSanity.c:130`). Better: stop passing free-form strings to `/bin/sh -c`; map IssueType → fixed `ExecStart=` argv arrays. |
| **S3 — World-RW SysV IPC carrying raw pointers** | At `src/rrdMain.c:157` use `msgget(ftok(...), IPC_CREAT | IPC_EXCL | 0600)` (or `IPC_PRIVATE`) and `msgctl(IPC_STAT)`-verify `uid==0` after open. **Stop transporting pointers**: redefine `msgRRDHdr` (`src/rrdCommon.h:103-106`) to carry a serialised, length-bounded copy of `data_buf` fields; on `msgrcv` (`src/rrdMain.c:46-51`) validate `mtype`∈{1,2,3}, length, and string contents before use. Add `PrivateIPC=yes` to the unit. |
| **S4 — Unauthenticated bus handlers** | In `_remoteDebuggerEventHandler` / `_rdmManagerEventHandler` (`src/rrdInterface.c:408`, `src/rrdIarmEvents.c:278`) verify `len == sizeof(IARM_Bus_RDMMgr_EventData_t)`, treat `pkg_inst_path`/`pkg_name` as untrusted (length-cap, charset-check, prefix-check). Deploy rbus ACLs restricting `setv` on `…RDKRemoteDebugger.*` to the WebConfig/tr69hostif component. |
| **S5 — Insecure `/tmp` usage** | Replace `ExecStartPre=-/bin/sh -c '/bin/mkdir -p /tmp/rrd'` with `RuntimeDirectory=rrd` + `RuntimeDirectoryMode=0700` and set `RRD_OUTPUT_DIR="/run/rrd/"` (`src/rrdRunCmdThread.h:39`). Add `PrivateTmp=yes`. Replace `mkdir→chdir→relative fopen` (`src/rrdJsonParser.c:533-544`, `src/rrdRunCmdThread.c:308-360`) with `mkdirat`/`openat(..., O_NOFOLLOW)` on a held dirfd. In `rrd_archive.c` use `open(O_NOFOLLOW|O_NOCTTY)` at `:154`, `fstatat(..., AT_SYMLINK_NOFOLLOW)` at `:249`, and `open(O_WRONLY|O_CREAT|O_EXCL,0600)`→`gzdopen()` at `:318`. Open `/tmp/.log-upload.lock` with `O_NOFOLLOW|O_CLOEXEC` (`src/rrd_upload.c:112`). |
| **S6 — Writable upload config** | Never `. /opt/dcm.properties` (`scripts/uploadRRDLogs.sh:109`) — parse it key=value as `src/rrd_config.c` does. In `rrd_config_parse_dcm_settings()` (`src/rrd_config.c:308-351`) and `rrd_config_query_rfc()` (`:261-286`), enforce a scheme+host allow-list on `http_upload_link`/`log_server`; do not let `/tmp/DCMSettings.conf` override RFC values. `fstat()` config files and reject if `st_uid != 0`. |
| **S7 — `snprintf`/`strncat` length misuse** | At `src/rrdJsonParser.c:525-531` and `src/rrdRunCmdThread.c:305-306`, clamp `dlen = min(dlen, sizeof(buf)-1)` (or check `dlen >= sizeof(buf)` and bail) before using it as an offset. At `src/rrdRunCmdThread.c:357` use `snprintf(finalOutFile, sizeof finalOutFile, "%s/%s", dirname, RRD_OUTPUT_FILE)`. At `src/rrdInterface.c:463-467` allocate `len+1` and NUL-terminate. Cap incoming rbus string length (e.g. 128) in `_remoteDebuggerEventHandler()`. |
| **S8 — msgpack decoder hardening** | In `__finder()` (`src/rrdMsgPackDecoder.c:47-67`) return NULL when `val.type != expect_type` in **all** branches. In `process_remotedebuggerdoc()` (`:388-397`) verify `obj->type == MSGPACK_OBJECT_MAP` and NULL-check `obj1/obj2/obj3` before deref. Fix `match()` (`src/rrdMsgPackDecoder.h:37`) to compare `key.size == strlen(s) && memcmp(...) == 0`. Use `size_t` with overflow check in `getReqTotalSizeOfIssueTypesStr()` (`:301-312`). |
| **S9 — Memory ownership** | After `free(rbuf->mdata)` at `src/rrdEventProcess.c:47`, set `rbuf->mdata = NULL` and `free(rbuf)`. Free `rbuf`/`rbuf->mdata` on the `EVENT_MSG` path. `strdup()` `jsonPath` at `src/rrdEventProcess.c:87`. Do not log `sbuf->mdata` after `RRDMsgDeliver()` at `src/rrdInterface.c:493`. Replace `system("rm -rf %s")` (`src/rrd_upload.c:193-196`) with `nftw()`+`unlinkat()`. |
| **S10 — systemd hardening** | Add to `scripts/remote-debugger.service`: `User=` (dedicated uid) or at minimum `CapabilityBoundingSet=`, `NoNewPrivileges=yes`, `ProtectSystem=strict`, `ProtectHome=yes`, `PrivateTmp=yes`, `PrivateIPC=yes`, `RestrictNamespaces=yes`, `SystemCallFilter=@system-service`, `Restart=on-failure`. Move the `.path` trigger off world-writable `/tmp/wifi_initialized` (`scripts/remote-debugger.path:23`). If root execution of debug commands is required, confine the `systemd-run` transient unit with `--property=ProtectSystem=strict --property=ReadOnlyPaths=/` and an explicit allow-list of `ExecStart` binaries instead of `/bin/sh -c`. |
